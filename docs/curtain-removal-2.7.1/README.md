## 原因与处理

代码确认两处整体覆盖：Mist提交32片相机朝向切片，以半球密度积累；Refraction提交一张相机朝向覆盖面，对其背景副本统一乘(.42,.68,.94)。前者0.95光学系数过浓，后者与背景叠合形成明显的染色区域。实录与此一致，但没有分层GPU抓帧，无法量化两层各占多少。

本次先彻底关闭Mist像素输出，保留材质段兼容DLL；Refraction移除整体压暗染蓝，并将Alpha限定为裂口与很弱的邻近宽带。刀光蓝色能量修正、沿刀路烟带与烟丝保持原样。C++、DLL、伤害、按键、角色动画、时间恢复、清理、配置未改。

这是去除失败覆盖层的热修，没有实现新的三维体积雾。透明面片可以作为粒子或体积渲染的绘制载体，但必须形成空间深度和连续密度；不能把一张背景滤色面当作真实雾气。本次删除的是观众直接看得到的覆盖效果，不继续调浓度来包装幕布。
