## 问题与修正

|问题|直接证据|这次实现|
|---|---|---|
|刀光泛白|视频冷白线条；旧Vertex把(.65,.85,1)乘亮度后逐通道截断，亮度1.6时顶点变成(1,1,1)|RGB除共同峰值保留色相比值，Alpha独立传0..2亮度；自有Glow27解码并乘入RGB，仍ONE ONE混合；主/源刀光统一标量压缩HDR峰值|
|蓝烟过薄|旧32层主体光学系数0.16，画面暖色背景占主导|主体光学系数0.95；保留归一化切片厚度与Beer-Lambert累积，不逐片增加同一份不透明度|
|空间冷暗不明显|旧局部冷色乘子(.94,.975,1.015)近乎原色|改为(.42,.68,.94)，按既有初斩/收刀及切面生命期作用于半球背景副本，保留细节、深度和退场|
|颗粒、雾霾感|独立尘烟/烟丝轮廓加原细密噪声堆叠；视频有灰蓝斑点|新512px周期低频场供主体与辅助烟带共同采样、旋流输运；主烟用深蓝至青蓝色带；原烟形图集只作8%弱调制；压低144尘烟、48烟带和96烟丝的透明度权重|

需要更正一个因果表述：旧Vertex确实会丢失色相比值，但旧Glow材质之后仍乘蓝色HDR系数，所以“顶点为白色”本身不足以证明最终像素一定是纯白。最终泛白还受多层加法、HDR曝光和显示映射影响。本次同时修正顶点、主刀光和源刀光三个环节；不会把静态模型当作最终画面保证。
