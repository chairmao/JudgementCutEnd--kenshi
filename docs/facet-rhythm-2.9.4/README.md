1. 揭开：对应刀路投影到每片当前世界朝向，源顶点坐标归一为0..1，经GPU插值沿方向揭开原遮罩。用0.36剪辑秒（实际0.12秒）完成，而非整片直接出现；没有增加边框、纹样或额外光源。近乎垂直的退化投影回退本片局部X。
2. 中期偏折：保留几何独立转动，背景位移响应随偏折进度增加，三片终值分别为0.95、0.65、0.82，初值0.28；都不超过已验收的原位移上界36像素。源折射强度仍单独传递，没有增加刀光/雾的亮度。

4. 日志：出生/三片停留/第一片分离/第二片分离/末片淡出共五阶段，每片各一条，最多15条阶段记录和1条激活记录。新增揭开/响应数值；投影包围盒仍仅是深度与遮罩测试前的上界，不能当实际GPU可见像素。
