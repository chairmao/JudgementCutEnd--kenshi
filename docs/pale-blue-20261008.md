# 淡蓝配色修订：2.1-pale-blue-r1

本次只修改四个颜色资源并已同步到游戏模组，不改C++或DLL，也不需要用户重新编译DLL。游戏已关闭时完成更新；实际HDR画面和游戏运行时shader支持仍待测试。

## 直接证据与适配判断

本机Skyrim模组 JCE030CutAllActi.nif 的BSEffectShaderProperty第113块读取到蓝色RGB约(0.14610514,0.62186617,1)，亮度scale=2；ScreenFx/Finish对应粒子也使用该色值。
原blade_effect09/08 DDS按Alpha加权的RGB分别约(0.444,0.444,0.444)、(0.7173,0.7173,0.7173)，属于灰度纹理。不能只复制这两张图就断言完整还原颜色。

原模组还有灰色材质和不同palette，gradbaneofthedead并非纯蓝；本次按用户明确的“偏淡蓝”要求作Kenshi适配，不冒称所有原材质都应蓝色，也不直接套用Skyrim的15/33倍亮度。
现有移植的高HDR增益与接近白色的顶点色容易降低可见色差，是根据代码与用户画面的推断；未测Kenshi实际曝光/泛光，所以不把静态tone-map模型当画面证明。

## 调整

- 主刀痕/范围圈：原等通道(4,4,4)HDR系数改为(1,2,3.2)，亮区仍发光，但更容易保留冰蓝色差。
- 原刀光纹理层：RGB tint=(0.56,0.80,1)，gain=2.4。
- 拖尾：tint=(0.48,0.74,1)，gain=1.4，略偏青蓝。
- 沿刀路细雾：tint=(0.66,0.88,1)，gain=1，呈淡蓝灰。
- 柔光/收刀闪光：tint=(0.70,0.90,1)，gain=1.8。
- 光屑：继续以原暖色图的灰度强度染成淡蓝，tint=(0.52,0.80,1)，gain=2.4。
- 光学空间高光/幻影：RGB系数(0.78,0.91,1)。
- 连续背景Mist灰雾与场景Refraction保持原样，不把整个画面染蓝。

新增colourTint为float3 uniform；program缺省(1,1,1)，material各层覆盖；shader只在RGB末端相乘。纹理Alpha、顶点Alpha、dustDetail、UV、图集和混合/深度合同均未更改。未增加纹理采样、材质段、粒子数量或运动循环。
