# 次元斩绝 JudgementCutEnd 1.1.2-dev

独立RE_Kenshi插件，项目E:\KenshiProject\2.Projects\JudgementCutEnd。用户已编译1.1.2-dev的Release|x64，本包包含时间恢复修复和1.1.1灰雾/残迹/空间裂光资源。1.0正式基线另存releases/1.0.0；游戏效果仍待验收。

选中可行动的人形玩家角色，单独按U；Esc/暂停取消，自由镜头。三倍演出：0.700秒拔刀、0.783秒裂空、1.717秒收刀集中结算、2.233秒恢复。没有冷却；松开后再按U清理旧演出并覆盖重播，长按不重复触发；世界降速0.001。中断前未结算伤害不补算，已结算伤害不回滚。

地面范围圈外半径固定为350，也是伤害范围，Radius=350直接表示实际半径；128段环带从演出开始显示，宽度向内展开，收刀后淡出。96条裂痕按角色朝向统一缩放中心、长度及光带宽度，完整匹配这个圆并保留相对分布；不是每条均长700。伤害以固定施放中心的XZ水平圆判定，包含边界、不因高度差缩小，覆盖圆内当前敌对非玩家目标；不截断前32/64人，按逻辑位置而非亮线/肢体碰撞判定。旧INI的Radius=150在新DLL中将表示实际半径150，需随本包一起更新INI。保留HDR增益4；坡地可能遮挡未贴地的平面圈，光晕不代表额外伤害范围。

每敌人最多96次原生addWound部位判断，每次100%装备近战武器对该目标的基准伤害；每击用独立参数副本，分别处理护甲、动态部位权重及医疗状态。用户旧DamageMultiplier=44忽略，固定单击1倍。死亡、实体失效、离圈或敌对/武器变化停止后续命中；原生部位ID次数汇总到日志。这里并非一次9600%伤害，也不是先预选96部位后直接写HP；原生选择和应用合为一次调用，同步逐击执行。

最后请求一次目标种族的大踉跄动作；无大动作则普通动作回退，无匹配动作记录原因。死亡、KO、非站立状态跳过站立反应。StaggerForceMultiplier=8只控制原生战斗反应力度（1-100配置，上限力度1,000,000），没有增加第二份医疗损伤或额外昏迷伤害，不保证固定秒数硬直。96次入口会增加收刀瞬间成本，实机需验证大量敌人卡顿。

无近战装备、拔刀失败或缓存不匹配仍允许演出，仅跳过伤害；换装撤销伤害资格。本插件拔出的同一把武器结束时原生收回，原本已手持的不动；旧固定CutDamage/BluntDamage、Cooldown非零、MaxTargets非零均忽略。声音使用assets/jce_sequence_fast.wav，保持采样率/音调、按三倍时轴安排参考片段。
